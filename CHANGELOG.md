# Changelog

This file records notable changes to the Cloud Security Drift Detector. GitHub release notes are generated using [the repository release-note categories](.github/release.yml) when a maintainer selects **Generate release notes** for a release.

## Unreleased

- Add advisory Terraform static security reporting, scheduled extended lint, Python CodeQL and secret-candidate review.
- Add a version-checked release workflow that builds source and wheel distributions, publishes SHA256 checksums and creates a build-provenance attestation when a maintainer publishes a release.
- Add a security policy, pull request checklist and security automation documentation.

Published release notes should explain user-facing changes, compatibility, fixes and security-relevant changes; do not publish findings containing live cloud account or resource metadata.
